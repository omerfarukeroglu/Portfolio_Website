# Ömer Faruk Eroğlu — Personal Portfolio Website

Personal portfolio website built with pure HTML5 and CSS3 for the **MIS326 Web Programming** course midterm project at İzmir Bakırçay University.

## Project Structure

```
├── index.html                  # Main HTML5 document with semantic sections
├── styles.css                  # External stylesheet
├── omer-faruk-eroglu-cv.pdf    # Downloadable CV (PDF)
├── images/                     # Profile photo, project images, page background, favicon
└── screenshots/
    └── desktop.png             # Full-page screenshot of the website
```

## Features

- **Semantic HTML5 Structure**: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>` and `<footer>` elements.
- **Plain CSS Styling**: One external stylesheet using element, class and ID selectors. The layout is built with `width`, `margin`, `padding` and `float`. No CSS or JavaScript frameworks.
- **Glass-Style Cards**: Half-transparent backgrounds with `backdrop-filter`, rounded corners, soft shadows and smooth `:hover` transitions.
- **Clean Content**: Semantic headings, descriptive `alt` attributes and checked links.
- **Downloadable CV**: A direct download link for my curriculum vitae as a PDF.
